# Data Science Internship — Final Project Submission

This repository contains two Data Science projects developed as part of my internship assignment. Both projects demonstrate practical applications of data analysis, machine learning, forecasting, and decision-support techniques.

## Project 1 — Customer Lifetime Value and Churn Intelligence

**Folder:** `DS-01-Customer-Churn/`

A customer analytics system designed to predict customer churn, estimate customer lifetime and value, identify key churn drivers, and support data-driven customer retention decisions.

**Key Technologies:** Python, Pandas, LightGBM, SHAP, Lifelines, SQL, Streamlit.

- [View Source Code and Documentation](./DS-01-Customer-Churn/)
- [Watch Project Demo](https://drive.google.com/file/d/1PiJ29u2eYRAuuduipAquVYj6PpUyGovo/view?usp=sharing)

The project README includes setup instructions, implementation details, evaluation results, and limitations.

## Project 2 — Nationwide Demand Forecasting and Inventory Optimization

**Folder:** `DS-02-Demand-Forecasting/`

A demand forecasting and inventory optimization prototype that compares multiple forecasting approaches, reconciles forecasts across product and store levels, and generates inventory recommendations using mathematical optimization.

**Key Technologies:** Python, Prophet, LightGBM, PyTorch Forecasting, Darts, OR-Tools, Plotly Dash.

- [View Source Code and Documentation](./DS-02-Demand-Forecasting/)
- [Watch Project Demo](https://drive.google.com/file/d/18bAg150uwp9Z8Wg5L5_ShWg256MyDFg4/view?usp=sharing)
- [View Project Presentation](./DS-02-Demand-Forecasting/presentation/Demand_Forecasting_Inventory_Intelligence.pptx)

The project README includes setup instructions, architecture, evaluation results, and implementation limitations.
