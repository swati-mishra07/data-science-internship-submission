# Data Science Internship — Final Project Submission

This repository contains two Data Science projects developed as part of my internship assignment.

## Project 1 — Customer Lifetime Value and Churn Intelligence

**Folder:** `DS-01-Customer-Churn/`

A customer analytics system designed to predict churn, estimate customer lifetime and value, explain churn drivers, and support retention decisions.

**Key technologies:** Python, Pandas, LightGBM, SHAP, Lifelines, SQL, Streamlit.

- [View source code and documentation](./DS-01-Customer-Churn/)
- [Watch project demo](https://drive.google.com/file/d/1PiJ29u2eYRAuuduipAquVYj6PpUyGovo/view?usp=sharing)
- Setup instructions, implementation details, results, and limitations are documented in the project's README.

## Project 2 — Nationwide Demand Forecasting and Inventory Optimization

**Folder:** `DS-02-Demand-Forecasting/`

A demand forecasting and inventory optimization prototype that compares forecasting approaches, reconciles forecasts across product and store levels, and generates inventory recommendations using mathematical optimization.

**Key technologies:** Python, Prophet, LightGBM, PyTorch Forecasting, Darts, OR-Tools, Plotly Dash.

- [View source code and documentation](./DS-02-Demand-Forecasting/)
- [Watch project demo](https://drive.google.com/file/d/18bAg150uwp9Z8Wg5L5_ShWg256MyDFg4/view?usp=sharing)
- [View project presentation](./DS-02-Demand-Forecasting/presentation/Demand_Forecasting_Inventory_Intelligence.pptx)
- Setup instructions, architecture, evaluation results, and limitations are documented in the project's README.
